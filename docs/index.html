Logistic-regression analysis

Adjusted fatal-crash associations in 404,508 Brazilian records.

A multivariable logistic regression on Brazilian crash records compared fatal-crash odds across reported causes while controlling for time of day, road delineation, and weather. The published artifacts expose the candidate models, selected specification, coefficient result, input checksum, and runtime environment.

Interpretation

Adjusted association, not a causal effect.

The reported 11.52× compares crashes attributed to pedestrians walking in the road with alcohol-related crashes, conditional on the selected covariates. It does not mean pedestrian behavior causes fatality odds to increase by that amount. The interval is model-based and assumes independent records and a correctly specified logistic model.

The source file is not republished. The reproduction script records its MD5 checksum (8b2672d2451e806cd7a71231ecad4cd7) so the exact input can be checked. The model excludes 58,644 rows whose road delineation was recorded as “Not Reported”; that exclusion and the resulting 404,508-row cohort are visible in the result artifact.
